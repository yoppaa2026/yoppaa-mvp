## 🐛 BUG CORRIGÉ — Bouton « Retour » dans la démo iframe

**Problème signalé** : lors d'une démonstration sur PC, cliquer sur le bouton « Retour » dans l'application (à l'intérieur de l'iframe iPhone) faisait reculer la page parente du navigateur au lieu de naviguer dans l'iframe.

**Cause** : par défaut, un iframe partage son historique de navigation avec son parent.

**Correction** : ajout de l'attribut HTML `sandbox="allow-scripts allow-same-origin allow-forms allow-popups allow-modals"` sur tous les iframes (slides démo + Mobile Frame). Cela isole l'historique de l'iframe **sans casser** les fonctionnalités essentielles (JavaScript, localStorage, formulaires de signalement, etc.).
